A token launch radar: it ranks pre-token protocols by an implied token value modelled from TVL, seven-day momentum and time live without a token, and gives each one a concrete farm plan — a sortable, filterable dashboard with a detail view per protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```
